# SonicWave 🎵

SonicWave is a music-themed website built with HTML, CSS, and JavaScript. It features a modern interface with a dark and light mode toggle, allowing users to switch between different visual themes.

The project focuses on creating a clean, visually appealing, and responsive user interface while practising frontend development skills.

## ✨ Features

- Modern and visually appealing website design.
- Dark and light mode toggle.
- Responsive layout for different screen sizes.
- Interactive elements powered by JavaScript.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Theme switching and interactivity.
